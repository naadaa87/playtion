가챠샵에 처음 가면 "이번 시리즈 시크릿 나왔어?", "컴플까지 몇 개 남았어?" 같은 말이 들려요. 일본에서 건너온 말이 많아서 처음엔 낯설어요. 자주 쓰는 말을 네 묶음으로 정리했어요. 가챠가 처음이라면 [가챠 뜻부터 고르는 법까지](/magazine/what-is-gacha)를 먼저 읽어도 좋아요.

## 기본 용어

| 용어 | 뜻 |
|---|---|
| 가챠 | 돈을 넣고 손잡이를 돌리면 캡슐에 든 장난감이 랜덤으로 나오는 뽑기, 또는 그 기계예요. 손잡이를 돌릴 때 나는 '가챠가챠' 소리에서 온 일본말이에요 |
| 캡슐토이 | 가챠의 정식 이름이에요. 캡슐에 든 작은 장난감이라는 뜻이에요 |
| 가샤폰 | 일본 반다이의 캡슐토이 상품 이름이에요. 우리나라에서는 가챠와 같은 뜻으로도 써요 |
| 가챠샵 | 가챠 기계를 여러 대 모아 둔 매장이에요. 캡슐토이 매장이라고도 해요 |
| 1회 가격 | 한 번 돌리는 값이에요. 기계 앞 라벨에 적혀 있어요 |
| 시리즈 | 같은 주제로 묶어 한 기계에 넣은 상품 묶음이에요 |
| 라인업 | 한 시리즈에 들어 있는 종류 목록이에요. "라인업 5종"처럼 말해요 |
| 라인업 안내지 | 기계 앞에 붙은 종류 그림과 가격 안내예요. 일본에서는 다이시(台紙)라고 불러요 |

## 수집할 때 쓰는 말

| 용어 | 뜻 |
|---|---|
| 시크릿 | 라인업 안내지에 그림이 공개되지 않은 숨은 종류예요. 다른 종류보다 적게 들어 있는 경우가 많아요 |
| 레어 | 다른 종류보다 적게 들어 있어 잘 안 나오는 종류예요 |
| 컴플 | 컴플리트(complete)의 줄임말이에요. 한 시리즈의 전 종류를 다 모으는 걸 말해요 |
| 중복 · 다부리 | 이미 가진 종류가 또 나오는 거예요. 다부리는 일본어 다부리(ダブり)에서 온 말이에요 |
| 최애 | 가장 좋아하는 캐릭터나 종류예요 |
| 개봉 · 미개봉 | 캡슐을 연 것과 캡슐째 그대로 둔 것이에요. 교환이나 판매할 때 상태를 나누는 기준이 돼요 |
| 교환 | 중복을 다른 사람의 다른 종류와 바꾸는 거예요 |
| 재판 | 품절된 시리즈를 제조사가 다시 만들어 내놓는 거예요 |
| 단종 · 절판 | 더 이상 새로 나오지 않는 시리즈예요. 구하기 어려워 교환 시장에서 귀해져요 |

## 상품 종류

| 용어 | 뜻 |
|---|---|
| 피규어 | 캐릭터나 사람, 동물을 입체로 만든 모형이에요 |
| 미니어처 | 음식, 가구, 가전처럼 실제 물건을 작게 줄인 모형이에요. 어른 수집가에게 인기가 많아요 |
| 소프비 | 소프트 비닐로 만든 말랑하고 가벼운 피규어예요. 일본어 소후비(ソフビ)에서 온 말이에요 |
| 아크릴 키링 · 스탠드 | 투명한 아크릴 판에 그림을 인쇄한 키링이나, 받침에 끼워 세워 두는 소품이에요 |
| 마스코트 · 인형 키링 | 가방에 다는 작은 봉제 인형이나 고무 마스코트예요 |
| 블라인드 박스 | 상자에 든 랜덤 상품이에요. 가챠처럼 열기 전까지 무엇이 들었는지 몰라요 |
| 종이 캡슐 | 플라스틱 대신 종이로 만든 캡슐이에요. 쓰레기를 줄이려고 쓰는 제조사가 늘고 있어요 |

## 매장에서 쓰는 말 (플레이션 기준)

| 용어 | 뜻 |
|---|---|
| 개봉대 | 캡슐을 여는 자리예요. 작은 부품이 바닥에 흩어지지 않게 해 줘요 |
| 빈 캡슐 반납함 | 다 쓴 캡슐과 설명서 종이를 넣는 곳이에요. 나눠 넣어 주세요 |
| 입고 · 신상 | 새 시리즈가 매장에 들어오는 거예요 |
| 가챠데이 | 플레이션에서 새 캡슐이 들어오는 날을 부르는 이름이에요 |
| 품절 | 기계 안 캡슐이 다 팔린 상태예요 |
| 기기 QR | 플레이션 기계마다 붙은 QR이에요. 찍으면 남은 상태와 다음 입고 알림을 볼 수 있어요 |
| 위치 번호 | "구역-열-단"으로 기계 자리를 알려 주는 번호예요. 홈페이지 상품 찾기와 같이 써요 |
| 교환회 | 중복을 들고 와 서로 바꾸는 모임이에요. 일정은 [컬렉터 클럽](/gacha/club)에서 알려 드려요 |

## 게임에서 말하는 가챠

모바일 게임에서 아이템이나 캐릭터를 무작위로 뽑는 것도 가챠라고 불러요. 이 말도 캡슐토이에서 나왔어요. 다만 이 글에서 말하는 가챠는 실제 캡슐에 든 장난감을 뽑는 캡슐토이예요.

## 자주 묻는 질문

### 다부리는 무슨 뜻인가요?

이미 가진 종류가 또 나온 중복을 말해요. 일본어 다부리(ダブり)에서 온 말이에요. 중복은 [교환하는 방법](/magazine/gacha-duplicate-trade)을 참고해 주세요.

### 컴플은 무슨 뜻인가요?

컴플리트(complete)의 줄임말로, 한 시리즈의 전 종류를 다 모으는 걸 말해요. "컴플했다"처럼 써요.

### 시크릿은 얼마나 안 나오나요?

시리즈마다 다르고, 비율을 공개하지 않는 경우가 많아요. 종류 수로 따져 보는 방법은 [가챠 확률 계산 글](/magazine/gacha-odds-secret)에 정리했어요.

### 재판과 재입고는 다른가요?

재판은 제조사가 품절된 시리즈를 다시 만드는 것이고, 재입고는 매장에 같은 상품이 다시 들어오는 거예요. 재판이 되면 여러 매장에 재입고될 수 있어요.
