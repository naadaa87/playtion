# 이미지 넣는 곳 (assets/img)

이 폴더에 **정해진 파일 이름**으로 이미지를 넣고 GitHub에 올리면(push),
홈페이지에 자동으로 반영돼요. 코드는 건드릴 필요가 없어요.

## 1) 로고 (권장: 투명 PNG)
| 파일 이름 | 쓰이는 곳 | 추천 |
|---|---|---|
| `logo.png` | 상단 헤더 · 모바일 메뉴 | 가로형, 배경 투명, 높이 80px 이상 |
| `logo-white.png` | 하단 푸터(어두운 배경) | 흰색/밝은 버전, 배경 투명 |

> 구글드라이브의 **"플레이션 로고 (화이트, 배경제거).png"** 를 `logo-white.png` 로,
> 밝은 배경용 로고를 `logo.png` 로 이름을 바꿔서 넣으면 돼요.
> (로고를 안 넣으면 기본 심볼 아이콘이 표시돼요 — 그대로 둬도 괜찮아요.)

## 2) 지점 사진 (권장: JPG, 가로형)
지금은 **각 지점의 실제 대표 사진**이 들어 있어요.
더 좋은 사진으로 바꾸고 싶으면 **같은 파일 이름으로 덮어쓰고 push**하면 즉시 교체돼요.

| 파일 이름 | 지점 |
|---|---|
| `store-sc1.jpg` | 신촌 플레이션 |
| `store-sc2.jpg` | 신촌 게임플레이션 2호점 |
| `store-sc3.jpg` | 신촌 게임플레이션 3호점 |
| `store-sadang.jpg` | 사당 게임플레이션 |
| `store-kondae.jpg` | 건대 플레이션 |
| `store-guui.jpg` | 플레이션 건대구의점 |
| `store-guri.jpg` | 구리 게임플레이션 |
| `store-ydp.jpg` | 영등포 플레이션 |

추천 크기: 가로 1200px 내외, 파일당 300KB 이하(가벼울수록 빨라요).
구글드라이브 AI 이미지 폴더의 "플레이션 게임파티룸 이미지모음 (1)~(8).jpg" 를
위 이름으로 바꿔 넣으면 바로 지점 사진으로 쓸 수 있어요.

## ⚠️ 저작권 주의
드라이브의 **"응용 이미지 로고 가이드"** 폴더 이미지는 상업적 사용이 불가해요.
로고 원본(대표님 소유)과 실제 매장 사진만 사용해 주세요.
